# StandMixer 0.2.8

StandMixer now uses **Sol 6.2** and **Astra 6.2** in place of Sol 6.1 and Astra 6. Existing editable assignments retain their effort levels, teams, overrides, and categories. Controller Auto continues using the current session model.

This release also includes the local 0.2.7 account-switching update:

- **Log out…** in the Codex and Mac connection dialogs signs out the shared Claude Code CLI profile after confirmation. You can then sign in with a different account.
- Logout preserves the linked profile and routing settings, verifies that sign-out completed, and never starts another login automatically.
- Improved cancellation and concurrent connection-record handling prevent false connection errors.

Existing applied settings and restore history retain their original model IDs until a reviewed change is applied. After upgrading, review and apply the 6.2 assignments you want, then start new agent sessions.

## Install or update

Run `/standmixer update` in Claude Code or `$standmixer update` in Codex. Add `--mac` to rebuild the optional Mac app. Open a fresh Codex chat or reload Claude plugins to load the updated interface; reopen the Mac app after updating.

The Mac app is **0.2.8 build 22**. The plugin packages include universal arm64/x86_64 helpers for macOS 14+. The optional Mac app remains a local build requiring compatible Swift 6 Apple Command Line Tools.
