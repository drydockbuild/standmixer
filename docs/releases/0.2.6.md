# StandMixer 0.2.6

StandMixer 0.2 adds clearer task routing and simpler editing for Claude Code and Codex. Version 0.2.6 includes the complete 0.2 update and the fixes verified during local use.

- Six work groups with optional subcategories, independently inherited settings, and ordered debugging escalation.
- Refined Fast, Optimized, and High-quality presets; separate development and release security choices; support for multi-model teams.
- Direct model and effort editing in Codex, automatic draft saves, Undo/Redo, clearer grouping, and aligned team assignments. Review & apply remains separate.
- Visible version information and content-versioned Codex panels to distinguish loaded UI from an updated installation.
- Optional Connect Claude for Codex using Claude Code's official browser login. Configured cross-provider routes check on opening settings or re-enabling a provider and prompt when the connection needs attention. Working connections stay quiet, and Not now leaves settings usable.
- Reliable connection checks for concurrent workers, bounded cancellation cleanup, and dialog dismissal scoped to the current connection attempt. Workers retain the caller’s locale, and status output omits account email and plan details.
- Claude workers use the linked CLI profile; credentials remain owned by Claude Code. StandMixer does not run inference to configure settings.

Existing presets and native model defaults are preserved. Controller Auto keeps the current session model and effort.

## Install or update

Requires macOS 14+, Git, and an installed Claude Code or Codex CLI. See the [installation instructions](https://github.com/drydockbuild/standmixer#install).

Existing installations can run `/standmixer update` in Claude Code or `$standmixer update` in Codex. Reload Claude plugins or open a fresh Codex chat; restart the host if the new plugin has not loaded. Confirm **0.2.6** in the panel before testing. Review and apply only the routing changes you want.

The optional Mac app is **0.2.6 build 20**, built locally with `install-mac` or `update --mac`; it requires compatible Swift 6 Apple Command Line Tools. Follow the [upgrade procedure](../upgrade-test.md) for older installations.

## Scope

This release supports macOS. Automatic model discovery, quota-aware fallback, and Windows/Linux support are not included. The plugin packages include universal arm64/x86_64 helpers; the optional Mac app remains a local build.
